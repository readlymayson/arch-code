# my-ai-coder 🤖

Гибридная система автоматической генерации кода на базе **CrewAI** + **LangGraph** + **DeepSeek V4** с изолированным исполнением в Docker.

## Архитектура

```
┌──────────────────────────────────────────────────┐
│                   CrewAI                         │
│  ┌──────────────────────────────────────────┐    │
│  │   Architect Agent (DeepSeek-V4-Pro)      │    │
│  │   • читает документацию из knowledge/    │    │
│  │   • пишет ТЗ + тесты                     │    │
│  │   • вызывает LangGraphCodingTool         │    │
│  └──────────────┬───────────────────────────┘    │
│                 │                                 │
│  ┌──────────────▼───────────────────────────┐    │
│  │   LangGraphCodingTool (CrewAI Tool)      │    │
│  └──────────────┬───────────────────────────┘    │
└─────────────────┼────────────────────────────────┘
                  │
┌─────────────────▼────────────────────────────────┐
│               LangGraph                          │
│  ┌──────────┐     ┌──────────┐                   │
│  │ generate │────►│   test   │──┐                │
│  └──────────┘     └──────────┘  │ (ошибка)       │
│       ▲                        │                │
│       └────────────────────────┘                │
│   (max 3 итерации, DeepSeek-V4-Flash)           │
└─────────────────┬────────────────────────────────┘
                  │
┌─────────────────▼────────────────────────────────┐
│         Docker (node:18-alpine)                  │
│   sandbox/ монтируется в /app                    │
│   node app.js или node --test                    │
└──────────────────────────────────────────────────┘
```

## Быстрый старт

```bash
# 1. Установить зависимости
pip install -r requirements.txt

# 2. Убедиться, что Docker доступен
docker info

# 3. Запустить
python main.py
```

## Структура

| Файл | Назначение |
|---|---|
| `main.py` | Точка входа — CrewAI оркестратор |
| `graph_worker.py` | LangGraph-цикл генерации и тестирования |
| `docker_manager.py` | Docker-песочница для Node.js |
| `tools/coding_tool.py` | Обёртка LangGraph в инструмент CrewAI |
| `tools/knowledge_reader.py` | Инструмент чтения доков агентами |
| `knowledge/` | Документация проекта (style-guide, API-контракты) |
| `sandbox/` | Папка, монтируемая в Docker-контейнер |

## Модели

- **Архитектор** — `deepseek-v4-pro` (медленнее, умнее)
- **Кодер** — `deepseek-v4-flash` (быстрее, для микро-итераций)
